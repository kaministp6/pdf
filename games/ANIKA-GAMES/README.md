# ANIKA GAMES — Sudoku Mind Puzzle

This Android project is stored separately under `games/ANIKA-GAMES` so the existing ANIKA PDF editor remains untouched.

## Features
- Sudoku-style number puzzle with Easy, Medium, and Hard presets
- Timer, score, mistake counter, keypad, erase, hint, check, and reset
- Android WebView shell and responsive dark UI
- GitHub Actions debug APK build

## Build
Open this folder in Android Studio, or use the repository-level GitHub Actions workflow named **Build ANIKA GAMES APK**. The generated debug APK is uploaded as the `ANIKA-GAMES-debug-apk` artifact.

Debug builds are for testing. A signed release APK requires release signing configuration.
